# Auditoría focalizada F2.8 — OpenSubtitles

**Fecha:** 2026-11-11
**Estado:** implementación verificada técnicamente; aceptación del propietario pendiente
**Alcance:** contrato/domain, adaptador Dio, servicio de aplicación, panel UI, composición/lifecycle, pruebas y documentación OpenSubtitles. No se revisaron módulos ajenos.

## Resumen

F2.8 integra búsqueda y descarga de subtítulos externos mediante un contrato
domain neutral, un adaptador HTTP Dio, un servicio de aplicación y un panel
opt-in del spike. Una prueba HTTP fake descarga un SRT a un directorio temporal,
lo entrega al coordinator y comprueba que libmpv real expone y selecciona la
pista externa. No se configuró una API key o bearer real; no se hizo tráfico a
OpenSubtitles ni se consumió cuota.

La revisión independiente secuencial detectó dos defectos adicionales en la
primera corrección: se perdía `Retry-After` en el GET de bytes y el envío del
campo con Enter podía iniciar búsquedas superpuestas. Ambos se corrigieron y
probaron. La segunda reevaluación independiente no encontró nuevos hallazgos
en ese alcance. No queda hallazgo P0/P1 conocido en F2.8. La CI completa de
este corte terminó en exit 0; F2.8 está técnicamente lista para revisión del
propietario, pendiente de aceptación formal.

  real ni todos los redirects posibles.

  regresión reproducible mostró que cancelar solo el listener no cancela el
  transporte fuente, mientras el `CancelToken` por request sí lo hace.

## Riesgos y criterios de reevaluación

- La búsqueda desde UI solo ofrece título en inglés; query permite IDs y
  filtros adicionales para futura composición de metadatos.
- No se probó API real, permisos/cuota de la cuenta, ni redirects reales.
- Archivos descargados permanecen en Application Support; no hay política de
  deduplicación/limpieza automática.
- El test libmpv confirma pista externa seleccionada, pero no texto dibujado en
  Fedora compositor.
- Repetir `git diff --check` y `python3 tools/ai/memory.py check` tras
  sincronizar las últimas entradas de memoria.

## Recomendación

No se conoce un hallazgo P0/P1 abierto en F2.8. El flujo de fixture local y
libmpv real está probado, el build específico y CI completa pasaron; no hay
evidencia de cuenta live ni de glifos visibles. Se recomienda F2.8 para revisión
del propietario con estas limitaciones explícitas. F2.8 no se marca como
aceptada por Codex.
