# F2.6 — Auditoría focalizada de subtítulos internos

Fecha: 2026-11-10. Estado: implementación y verificaciones ejecutadas; aceptación del propietario pendiente.

## Alcance

Revisión limitada a los cambios F2.6 en `app/lib/domain/player/subtitles`, el contrato/coordinator F2.4, el adaptador `media_kit`/libmpv, los controles del spike, las pruebas y documentación relacionada. No se modificaron catálogo, Drift, AniList ni Supabase.

El dominio modela `SubtitleTrackInfo`, `SubtitleStyle` y `HardsubPolicy`. Application serializa operaciones de selección/carga local/estilo/delay. Data configura libass, enumera y selecciona pistas, valida archivos regulares locales, aplica propiedades mpv y rechaza subtítulo externo cuando hardsub se confirma. La presentación permite seleccionar pista, ajustar tamaño, familia, texto/contorno, grosor, negrita, posición, ASS override y delay ±250 ms. La carga de fuentes externas continúa fuera del alcance de F2.6.

## Hallazgos

| Severidad | Hallazgo | Resultado | Evidencia / límite |

| P2 | Pérdida de selección/estilo al cambiar de fuente | Aceptado por ciclo de sesión | Identificadores de pista son de sesión; estilo es temporal, no persistente. Cambio de fuente corresponde a F2.7. |
| P2 | Estilos podían existir solo en pruebas de propiedad sin salida visible | Parcialmente verificado | Captura Wayland muestra frame y SRT interno visible. No acredita ASS, hardware ni todos los estilos. |

| P3 | Fontconfig no puede escribir caché de sistema | Limitación del entorno | Avisos durante CI; no se modificó sistema. La pista SRT sí se hizo visible. |
| P3 | Error EGL y fallback software | Limitación observada | El log indica EGL inválido y software rendering; compositor mostró video y texto. No se afirma decodificación acelerada. |
| P3 | Advertencia previa: selección de pista despausaba media | Refutado con evidencia | Fuente instalada `media_kit 1.2.6` `real.dart`: `setSubtitleTrack` agrega URI o establece `sid`; no modifica `pause`. El revisor retiró la afirmación. |
| P3 | Aviso visual si hardsub está ausente/desconocido | Diferido a F2.8 | F2.6 solo define estado/política; UI de proveedor/fuente externa no está implementada. |

- Flutter 3.47.9 aislado / Dart 3.13.7. `bash scripts/ci.sh`: exit 0; 40 pruebas Python de infraestructura, análisis Dart/Flutter, formato, checker de imports y 150 pruebas Flutter.
