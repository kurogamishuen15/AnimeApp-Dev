## Implementación

- Se añadió una prueba de integración que persiste un documento local, simula error remoto con `FakeSyncRemote` y demuestra que el documento local permanece intacto.
- Los contratos de credenciales, progreso, catálogo y sincronización se prueban con fakes manuales, SQLite real aislado o HTTP loopback según el adaptador. Ninguna prueba requiere cuenta, AniList real, keyring real o Supabase.
- `FakeSyncRemote` snapshottea profundamente payloads JSON para que mutaciones posteriores no cambien peticiones ya registradas.
- El checker de imports cubre ocho archivos bajo directorios `domain`; los fixtures sintéticos comprueban imports permitidos/prohibidos.
