  Linux release build, `check_imports`, `test_check_imports.sh` y `scripts/ci.sh`

## Correcciones

- `SettingsStore.watch` deduplica eventos mediante representación JSON validada;
  se reprodujo la emisión redundante por escritura de otra clave.
- AniList desactiva redirects y clasifica HTTP/GraphQL 401 como `AuthAppError`.
- El logger sustituye URL malformada por `[INVALID URL]` sin lanzar.
- Se añadieron pruebas de cache corrupta e integración completa de adaptadores.

## Revisiones

QA, seguridad, auditoría de código y arquitectura revisaron el alcance. Las
revisiones independientes fueron estáticas; las pruebas de comportamiento
están en el informe. Arquitectura permanece por capas y dominio Dart puro.

## Límites abiertos

- Uso de AniList depende de la revisión de elegibilidad frente a sus términos;
  número de solicitudes públicas: 0.
- No hay TTL/frescura definida para la cache; `cachedAt` es metadata técnica.
- Secret Service/keyring real y OAuth siguen sin validar.
- El progreso es documento JSON opaco; sync no tiene outbox ni políticas de
  conflicto/idempotencia/backoff.
- No existe sink de consola de producción ni integración de estos módulos al
  flujo visible de la aplicación.
- Flutter stable `3.47.9` conserva el fallo LSP Unicode; este resultado de CI
  corresponde al beta aislado y no cierra F0.4/F0.5.
- No se inició Fase 2.
